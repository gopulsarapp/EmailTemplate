## 🔤 Fonts (Email-Safe)

### Primary Font
- Arial, Helvetica, sans-serif

### Secondary / Fallback Fonts
- Segoe UI, Roboto, system-ui, sans-serif

### Font Size Guidelines
- **H1 / Headline:** 24–28px
- **H2:** 18–22px
- **Body Text:** 14–16px
- **Footer / Legal Text:** 12–13px

⚠ Custom web fonts (e.g., Google Fonts) are **not recommended** for email usage.
